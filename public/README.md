# sweetgram — минималистичный мессенджер

Вход по почте (код из письма) → имя и @юзернейм → поиск людей по юзернейму → личные чаты в реальном времени.
На телефоне работает как приложение (PWA): открыть сайт → «Добавить на главный экран».

**Функции:** регистрация и вход по коду, поиск по @юзернейму, чаты в реальном времени (WebSocket), «печатает…»,
«в сети» / «был(а) в…», галочки прочтения, счётчики непрочитанных, подгрузка истории, «Избранное» (заметки себе),
редактирование профиля, тёмный дизайн в стиле Liquid Glass и 9 тем (AMOLED по умолчанию, Midnight, Mint, Sunset, Lavender, Cherry, Ocean, Gold, Graphite), уведомления, пока приложение открыто или свёрнуто.

## Локальный запуск
```
npm install
npm start          # http://localhost:3000
```
Без настроек данные пишутся в `data/db.json`, а код входа печатается в консоль.

## Деплой на Render
1. Залейте папку в репозиторий на GitHub.
2. Render → **New → Blueprint** → выберите репозиторий. `render.yaml` сам создаст веб-сервис и базу PostgreSQL.
3. Заполните переменные для почты (см. ниже) → **Apply**.

### Почта (обязательна для реальных пользователей)
На бесплатном Render исходящий SMTP заблокирован, поэтому письма отправляются через HTTP API.

**Brevo (рекомендую: 300 писем в день бесплатно, свой домен не нужен):**
1. Зарегистрируйтесь на brevo.com → Senders, Domains & IPs → добавьте и подтвердите свою почту как отправителя.
2. SMTP & API → API Keys → создайте ключ.
3. В Render: `BREVO_API_KEY` = ключ, `MAIL_FROM` = подтверждённая почта.

**Или Resend:** `RESEND_API_KEY` и `MAIL_FROM` (нужен подтверждённый домен, иначе письма уходят только на ваш адрес).

Пока почта не настроена, коды видны в Render → Logs.

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | PostgreSQL (Render подставляет сам) |
| `BREVO_API_KEY` / `RESEND_API_KEY` | ключ почтового сервиса |
| `MAIL_FROM` | адрес отправителя |
| `MAIL_FROM_NAME` | имя отправителя (по умолчанию sweetgram) |

### Ограничения бесплатного Render
- Сервис засыпает после 15 минут без запросов — первое открытие занимает ~30–60 с.
- Бесплатная база Render живёт 30 дней. Для постоянной подойдёт бесплатный Postgres на neon.tech — вставьте его строку подключения в `DATABASE_URL`.

## Доступ из России без VPN
Render работает через Cloudflare, а российские провайдеры с 2025 года режут трафик к Cloudflare
(примерно 16 КБ на соединение) — сайт на `*.onrender.com` у многих не откроется без VPN.
Чтобы работало у всех, разместите sweetgram на российском хостинге — код тот же, ничего менять не нужно:

- **Timeweb Cloud → Apps** (или Amvera, Yandex Cloud Serverless Containers): подключите GitHub-репозиторий,
  тип — Node.js или Dockerfile (он лежит в корне), команда запуска `npm start`.
- База: управляемый PostgreSQL у того же хостинга → строку подключения в `DATABASE_URL`.
- Переменные почты те же (`BREVO_API_KEY`, `MAIL_FROM`).

## Фото профиля
Фото обрезается по кругу и сжимается до 400×400 прямо на телефоне, затем хранится в базе (таблица `avatars`) —
поэтому не пропадает при перезапусках на Render, где диск временный.
